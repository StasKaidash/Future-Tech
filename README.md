# Future1Tech

Multi-page website built with HTML, SCSS and JavaScript.

## 🔗 Live Demo
https://future1tech.netlify.app/

## 📄 Description
Future1Tech is a multi-page website consisting of 6 pages. The project demonstrates building structured layouts, navigation between pages, and implementing interactive elements.

## 🚀 Features
- Multi-page structure (6 pages)
- Responsive design (mobile / tablet / desktop)
- Form validation (client-side)
- Navigation between pages
- Clean and structured UI

## 🛠 Tech Stack
- HTML5
- SCSS (modular structure, reusable styles)
- JavaScript (ES6)

## 💡 What I Learned
- Building scalable multi-page websites  
- Working with SCSS architecture  
- Implementing form validation  
- Improving UI/UX structure  

## 📦 Deployment
Deployed via Netlify
